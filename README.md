## Question Format

All question sets follow a consistent format:

### Multiple Choice Questions (MCQs)
- Question statement with scenario (if applicable)
- 4 options labeled A-D
- Correct answer clearly marked
- Detailed explanation for the answer

### Long Answer Questions
- Question worth 10-15 marks
- Clear requirements and aspects to discuss
- 8 comprehensive bullet points as answers
- Each point covers a distinct aspect with technical depth

### Scenario-Based Questions
- Realistic business scenario with specific context
- Multiple sub-questions (typically 3 parts worth 5 marks each)
- Comprehensive answers with practical recommendations
- Focus on real-world application and critical thinking

## Target Audience

- **Students**: Studying Information Security, IT Audit, or Cybersecurity programs
- **Professionals**: Preparing for security certifications (CISSP, CISA, CISM, Security+)

3. **Training Programs**: Incorporate questions into security awareness and audit training

5. **Interview Preparation**: Review answers to prepare for security and audit role interviews
